# Gradual indexing rollout — 2 pages/day

Tracks the noindex-removal schedule for the 16 Alexandria/Cairo geo pages + `/printing/brochures`.
See plan: `~/.claude/plans/glimmering-dancing-planet.md`. Each day: remove `robots="noindex, nofollow"`
from that day's page(s), add them to `PAGES` in `astro/src/lib/sitemap-data.ts` (and drop them from
`NOINDEX_PATHS` there), commit, push, deploy via `scripts/deploy-astro.sh`, verify with curl.
